# Wireframes

The wireframes for the initial release are being designed. This document records the planned pages and the main information each should display.

## List of Pages

| Page | Main content |
| --- | --- |
| Sign Up | Name, email, password, submit form |
| Log In | Email, password, submit form |
| My Tasks | Selected tasks, progress state, Start/Stop actions, navigation to catalog |
| Task Catalog | Categories, difficulty labels, Add buttons |
| Task Timer | Selected task, elapsed time, Stop button |
| Profile | Name, total points, completed-task history |

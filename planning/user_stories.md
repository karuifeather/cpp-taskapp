# User Stories

## User Roles

- **Visitor:** Someone who has not signed in.
- **Registered user:** Someone with an account who can manage their tasks and progress.

## Stories

1. As a visitor, I want to create an account so I can keep a personal task list.
2. As a registered user, I want to log in so I can access my saved tasks.
3. As a registered user, I want to log out so I can end my session.
4. As a registered user, I want to browse a curated task catalog so I can find activities to work on.
5. As a registered user, I want to filter tasks by category so I can find relevant tasks quickly.
6. As a registered user, I want to see task difficulty so I can choose activities that fit my day.
7. As a registered user, I want to add a catalog task to my personal list so I can plan my activities.
8. As a registered user, I want to see today's selected tasks so I know what is pending.
9. As a registered user, I want to reschedule an unstarted task so I can adjust my plans.
10. As a registered user, I want to remove an unstarted task so I can keep my list relevant.
11. As a registered user, I want to start a timer for a task so I can track my work time.
12. As a registered user, I want to stop the timer when I finish so the app records my completion and points.
13. As a registered user, I want to see my completed tasks and total points so I can review my progress.
